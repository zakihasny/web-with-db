# Changelog

## 0.1.0 — 2026-08-07

- Added a three-route Nuxt application for the employee MySQL database.
- Applied BGN Web Design System v1.3.22 colors, typography, spacing, radius, border, button, form, and table tokens.
- Added the official `Wordmark24.svg`, `Wordmark32.svg`, and `Mark32.svg` assets without modification.

- Added a validated employee-entry form using a separate insert-capable database account.
